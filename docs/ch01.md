## 2. Python 基础

### 2.1 解释器与脚本文件

Python 代码有两种常见运行方式：

1. 在解释器中逐行输入，适合快速验证简单表达式；
2. 将代码保存为 `.py` 文件，适合编写和重复运行完整程序。

运行脚本的基本命令：

```bash
python 文件名.py
```

输出结果：取决于脚本中的具体代码。如果程序正常执行且代码中没有 `print()` 等输出语句，终端可能不会显示任何内容。

例如：

```bash
python ch01/hungry.py
```

输出：

```text
I am hungry
```

### 2.2 数据类型和变量

Python 常用的基本数据类型包括：

- 整数：`int`
- 小数：`float`
- 字符串：`str`
- 布尔值：`bool`，只有 `True` 和 `False`

Python 是动态类型语言，定义变量时不需要提前声明类型：

```python
count = 10
rate = 0.1
name = "Tom"
is_ready = True
```

输出结果：这段代码只完成变量赋值，没有终端输出。

可以使用 `type()` 查看对象的类型：

```python
print(type(count))
```

输出：

```text
<class 'int'>
```

### 2.3 列表和字典

列表用于按顺序保存多个值：

```python
numbers = [1, 2, 3, 4, 5]
print(numbers[0])
print(numbers[1:3])
```

输出：

```text
1
[2, 3]
```

需要注意：

- Python 的索引从 `0` 开始；
- `numbers[1:3]` 包含索引 `1`，但不包含索引 `3`；
- 列表中的元素可以读取、修改和切片。

字典使用“键—值”形式保存数据：

```python
person = {"name": "Tom", "age": 20}
print(person["name"])
```

输出：

```text
Tom
```

### 2.4 条件判断和循环

条件判断使用 `if`、`elif` 和 `else`：

```python
if is_ready:
    print("开始")
else:
    print("尚未准备好")
```

因为前面将 `is_ready` 设置为 `True`，所以输出：

```text
开始
```

循环可以使用 `for`：

```python
for number in [1, 2, 3]:
    print(number)
```

输出：

```text
1
2
3
```

Python 使用缩进表示代码块，通常每一级缩进使用 4 个空格。缩进不仅影响可读性，也直接决定程序结构。

### 2.5 函数

函数用于封装可以重复执行的处理：

```python
def greet(name):
    return "Hello, " + name


message = greet("Tom")
print(message)
```

输出：

```text
Hello, Tom
```

函数可以：

- 接收参数；
- 执行一组操作；
- 使用 `return` 返回结果；
- 减少重复代码。

### 2.6 类和对象

类用于把数据和相关操作组织到一起：

```python
class Man:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print("Hello, " + self.name + "!")


man = Man("Tom")
man.hello()
```

输出：

```text
Hello, Tom!
```

关键概念：

- `class` 用于定义类；
- `__init__()` 在创建对象时执行，用于初始化对象；
- `self` 表示当前对象本身；
- `self.name` 是对象保存的属性；
- `man.hello()` 是调用对象的方法。

后续实现神经网络时，会使用类来封装网络和各种层，因此需要理解类、属性和方法之间的关系。

## 3. NumPy

NumPy 是本书进行数值计算的核心工具。它能够方便、高效地处理向量、矩阵以及更高维的数据。

### 3.1 创建数组

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0])
y = np.array([2.0, 4.0, 6.0])
```

输出结果：这段代码导入 NumPy 并创建两个数组，没有终端输出。

`np.array()` 创建的对象是 NumPy 数组，也叫 `ndarray`。

### 3.2 数组运算

形状相同的数组可以进行对应元素的运算：

```python
print(x + y)
print(x - y)
print(x * y)
print(x / y)
```

输出：

```text
[3. 6. 9.]
[-1. -2. -3.]
[ 2.  8. 18.]
[0.5 0.5 0.5]
```

这里的 `x * y` 是对应元素相乘，并不是矩阵乘法。

数组也可以与单个数进行运算：

```python
print(x * 2)
```

输出：

```text
[2. 4. 6.]
```

NumPy 会把数字 `2` 自动应用到数组的每个元素上。

### 3.3 多维数组

```python
matrix = np.array([
    [1, 2],
    [3, 4],
])

print(matrix.ndim)
print(matrix.shape)
print(matrix.dtype)
```

在当前 64 位 Linux 环境中输出：

```text
2
(2, 2)
int64
```

- `ndim`：数组的维数；
- `shape`：数组各个方向的长度；
- `dtype`：数组元素的数据类型。

数组形状是后续学习神经网络时非常重要的概念。进行矩阵运算前，应先确认数据的 `shape` 是否符合要求。

### 3.4 广播

NumPy 可以在满足一定条件时，对形状不同的数组进行运算，这种机制称为广播：

```python
matrix = np.array([
    [1, 2],
    [3, 4],
])

print(matrix * 10)
print(matrix * np.array([10, 20]))
```

输出：

```text
[[10 20]
 [30 40]]
[[10 40]
 [30 80]]
```

广播可以减少重复代码，但如果没有注意数组形状，也可能得到与预期不同的结果。

### 3.5 访问数组元素

NumPy 数组支持索引、切片和条件筛选：

```python
x = np.array([10, 20, 30, 40])

print(x[0])
print(x[1:3])
print(x[x > 20])
```

输出：

```text
10
[20 30]
[30 40]
```

条件表达式 `x > 20` 会生成布尔数组，再利用这个布尔数组筛选符合条件的元素。

## 4. Matplotlib

Matplotlib 用于将计算结果可视化。

### 4.1 绘制曲线

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(0, 6, 0.1)
y = np.sin(x)

plt.plot(x, y)
plt.show()
```

输出结果：程序不会在终端输出数值，而是打开一个绘图窗口，显示横坐标约为 `0～6` 的正弦曲线。

- `np.arange()` 按指定间隔生成数组；
- `np.sin()` 计算数组中每个元素的正弦值；
- `plt.plot()` 绘制曲线；
- `plt.show()` 显示图像窗口。

### 4.2 完善图表信息

```python
plt.plot(x, np.sin(x), label="sin")
plt.plot(x, np.cos(x), linestyle="--", label="cos")
plt.xlabel("x")
plt.ylabel("y")
plt.title("sin & cos")
plt.legend()
plt.show()
```

输出结果：程序打开一个绘图窗口，其中：

- `sin` 是实线；
- `cos` 是虚线；
- 横轴名称为 `x`，纵轴名称为 `y`；
- 标题为 `sin & cos`；
- 图例用于区分两条曲线。

- `label`：设置曲线名称；
- `linestyle`：设置线条样式；
- `xlabel()`、`ylabel()`：设置坐标轴名称；
- `title()`：设置图表标题；
- `legend()`：显示图例。

只有为曲线设置 `label` 后，`plt.legend()` 才能显示有意义的图例。

### 4.3 显示图片

```python
import matplotlib.pyplot as plt
from matplotlib.image import imread

image = imread("图片路径")
plt.imshow(image)
plt.show()
```

输出结果：将 `"图片路径"` 替换为真实图片路径后，程序会打开绘图窗口并显示该图片；终端通常没有文本输出。

- `imread()` 读取图片；
- `imshow()` 将图片放到图表中；
- `show()` 显示图片。

尽量使用相对于项目目录的相对路径，避免写死个人主目录的绝对路径。绝对路径在文件移动或更换电脑后通常会失效。
